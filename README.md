# Moji ispiti

Lična platforma za pripremu ispita (VŠJ Novi Sad): testovi, skripte za čitanje i PDF, kartice, ponavljanje grešaka i praćenje napretka.

**Sajt:** https://stankovic-dusan-skp.github.io/ljubicica-ispiti/

| Folder | Predmet |
| --- | --- |
| `javno-zdravlje/` | Javno zdravlje |
| `poslovna-komunikacija/` | Veštine poslovne komunikacije |
| `metodologija-zo/` | Metodologija zdravstvenog obrazovanja i promocija zdravlja |
| `organizacija-zdravstva/` | Organizacija zdravstvene delatnosti (položeno) |

Svaki predmet ima `index.html` (testovi), `pitanja.js` (baza pitanja), `skripta.html` (skripta za čitanje) i `skripta.pdf`.
Zajednički dizajn i kod su u `assets/`. Napredak se čuva samo u pregledaču korisnika (localStorage), trajno.
