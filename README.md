# Moji ispiti

Testovi i skripte za pripremu ispita, svi predmeti na jednom mestu.

Sajt: https://stankovic-dusan-skp.github.io/ljubicica-ispiti/

| Predmet | Folder |
| --- | --- |
| Organizacija zdravstva | `organizacija-zdravstva/` |
| Javno zdravlje | `javno-zdravlje/` |
| Veštine poslovne komunikacije | `poslovna-komunikacija/` |
| Metodologija zdravstvenog obrazovanja i promocija zdravlja | `metodologija-zo/` |

Svaki folder ima `index.html` (testovi) i `skripta.pdf`. Početna strana (`index.html`) je dashboard sa napretkom i odbrojavanjem do ispita.
